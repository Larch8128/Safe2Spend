# Safe Spend Planner

A budgeting app. I budget for bills, pots monthly, then I have a monthly (safe to spend) figure for food, fuel and other, split dynamically into the weeks of the month, and , any part weeks. Essentially, I want to see a dashboard with the total monthly safe to spend amount, weekly safe to spend and daily safe to spend, all have a starting balance option. Each category (on its own row) has three amounts in columns. Daily weekly and monthly. Each can be toggled on or off for user preference is you can have 1, 2 or three showing. You can also toggle on a view that shows all weeks of the month (between a selectable pay day). The categories should be able to be added, deleted or renamed. After spending, I can allocate an amount to any category for the current week, and it will reduce the amount allocated to the current category.
